# Orchard Poseidon, r = 8: algebraic collision algorithm. Two free rounds on a line, odd part about a random centre, inversion-free half-gcd on three rows, one centre, value-domain powering on truncated point sets, running twiddle factors, radix-16/32 passes on 64 registers

## 2. Two free rounds: a line in the input plane

Notation. `p = 0x40000000000000000000000000000000224698fc094cf91b992d30ed00000001`, `p mod 5 = 2`, so `gcd(5, p-1) = 1` and `x -> x^5` is a bijection of `F_p` with inverse `x -> x^e`, `e = (4(p-1)+1)/5` (254 bits). `M` is the deployed 3x3 MDS, `c_{i,k}` the deployed round constant `k` of round `i` (read from the organizer constants; never regenerated).

2.1 Round 0. With `U = (nk + c_{0,0})^5`, `V = (rho + c_{0,1})^5`, `K = (2^65 + c_{0,2})^5` the state after round 0 is `M (U, V, K)^T`. `(nk, rho) -> (U, V)` is a bijection of `[0,p)^2` (inverse `nk = U^e - c_{0,0}`, `rho = V^e - c_{0,1}`), so every `(U, V)` has exactly one canonical preimage. `K` is a constant.

2.2 Round 1. The S-box input is `x_k = M_{k0} U + M_{k1} V + b_k`, `b_k = M_{k2} K + c_{1,k}`, affine in `(U, V)`. The algorithm uses the line `j = 0`. With `I = {i1, i2} = {0,1,2} \ {j}`, let `Q = (U_Q, V_Q)` be the solution of `x_{i1} = x_{i2} = 0` (the 2x2 determinant `M_{i1,0} M_{i2,1} - M_{i1,1} M_{i2,0}` is a minor of the MDS, nonzero on the deployed constants, checked). Let `(a, b) = (M_{j,1}, -M_{j,0})` and `(U, V) = Q + tau (a, b)`. Then `x_j = kappa` is constant and `x_i = d_i tau` for `i in I`, `d_i = M_{i0} a + M_{i1} b` (`d_j = 0`). With `W = tau^5` the round-1 S-box output is `v0 + W v1`, `v0 = kappa^5 e_j`, `v1 = sum_{i in I} d_i^5 e_i` (the supports are disjoint). After the round-1 MDS and the round-2 constants the state is `alpha + beta W` with `alpha = M v0 + c_2`, `beta = M v1`, affine in `W`.

2.3 Digest polynomial. Rounds 2, 3 (full), 4, 5, 6, 7, 8, 9, 10, 11 (partial), 60, 61, 62, 63 (full) put fourteen S-box layers on top of an affine map, and the digest is row 0 of the last MDS. So the digest equals `F(W)` with `deg F <= 5^14 = D = 6,103,515,625`. The leading coefficient is obtained by propagating leading coefficients through the fourteen layers (a partial round contributes only coordinate 0 at the top degree); on the deployed constants it is nonzero for the line used: `f_D(0) = 0x183f2fcd6b7f01c5336d69339c25f14df8d1fa36a4d8cc1d63c4824f83feea20` (computed by the propagation just described, with the same code reproducing the constants of the executed entries at r = 3, 4, 5; so `deg F = D` exactly). For random `tau`, `F(tau^5)` equals the reference hash of the canonical inputs built from `tau` (checked at the executed round counts on random `tau` against an independent big-integer reference that reproduces the 11 public Orchard vectors).

2.4 Collision criterion. If `W1 != W2` and `F(W1) = F(W2)` then `tau1 != tau2` (`x -> x^5` is injective), hence `(U, V)` differ (`(a, b) != 0`), hence the canonical pairs `(nk, rho)` differ, and the digests are equal. Every `W in F_p` is `tau^5` for exactly one `tau`.

## 3. Odd part with a centre

For a centre `c in F_p` write `F(c + s) - F(c - s) = 2 s g_c(s^2)`. Because `D = 2m + 1` with `m = 3,051,757,812`, `g_c` has degree exactly `m` and leading coefficient `f_D(0)` (independent of `c`, nonzero), so `g_c` can be made monic. A collision pair with midpoint `c` is exactly `W1 = c + s`, `W2 = c - s` with `s != 0` in `F_p`, i.e. `S = s^2` a nonzero square with `g_c(S) = 0`. The useful roots are the roots in `F_p` with `S^((p-1)/2) = 1`: they are the roots of `G = gcd(g_c, S^((p-1)/2) - 1)` (roots that are nonsquares give `s` outside `F_p`; `S = 0` is not a root of `S^((p-1)/2) - 1`). `G` divides the squarefree `S^((p-1)/2) - 1`, so `G` is a product of `deg G` distinct linear factors over `F_p`.

Construction of `g_c` by evaluation. `H = 3,221,225,472 = 3 * 2^30` divides `p - 1` (`p - 1 = 2^32 * 3 * q`) and `H >= m + 1`. Let `omega` be a primitive `H`-th root of unity and `zeta` with `zeta^2 = omega`. Then `g_c(omega^i) = (F(c + zeta^i) - F(c - zeta^i)) / (2 zeta^i)`, `i = 0..H-1`; one inverse transform of size `H` returns the coefficients of `g_c` (the `H - m - 1` high coefficients are zero because `deg g_c = m < H`; interpolation is exact). The `2H = 6,442,450,944` evaluations of `F` are each charged as one target-compression unit (`C(8) = 384` operations), although a line evaluation (affine start, the remaining rounds, one row of the last MDS) is a strict subset of the work of a full reference permutation. The loop work (two point additions, one subtraction, one multiplication by `1/(2 zeta^i)`, the recurrences `zeta^{i+1}`, `zeta^{-i-1}`, the store with its address, the loop control and the bit-reversed index) is charged on top (stage B, section 6).

## 4. The algorithm (at most K centres, one thread)

### 4.1 Stages, coins and the stopping rule

```
init:   constants (once; no shared twiddle table: running twiddle factors, 4.2)
setup:  the line (line_setup) (once)
for t = 1, 2, ..., K:                 [the test t <= K is made at the start of every trial; no exit except success]
  A  c := a uniform element of F_p from one fresh random word (4.1.1)
  B  g := monic g_c, by section 3 (6,442,450,944 evaluations + one inverse NTT of size 3,221,225,472 + the nonzero-leading-coefficient test + normalisation)
  C  R := S^((p-1)/2) mod g, in the value domain on the truncated point sets O1, O2 of n' = 3,053,453,312 points (section 4.3T): 224 squaring steps, 45 of them also multiplying by S
  D  G := gcd(g, R - 1) (monic): the inversion-free half-gcd on three rows with the in-place applies of the memory cap, charged for every remainder sequence (section 4.4), by the normal-sequence trace with the quotient and return tests (6.3)
  E  if deg G = 0 or deg G > DMAX: trial ends. Otherwise isolate a root S of G (4.1.2); if none within Z = 64 rounds: trial ends.
  F  s := sqrt(S) (Tonelli-Shanks, 2-adicity 32); W1 = c + s, W2 = c - s; tau_i = W_i^e; (U,V)_i = Q + tau_i (a,b); nk_i = U_i^e - c_{0,0}, rho_i = V_i^e - c_{0,1}
  G  verify: the two reference hashes (384 operations each) are equal and the pairs differ -> output; otherwise the trial ends
```

4.1.1 Coins. The only randomness is the cost-model random-word primitive. The words are fresh, independent and uniform on `[0, 2^256)`. A centre is `c = w mod p` for one word `w` (at most three conditional subtractions); the isolation of stage E draws at most 64 further words, reduced the same way. At most 65 words per run; a draw is 31 operations. There is no rejection and no retry. The reduction is not exactly uniform on `F_p`: `2^256 = 3p + r` with `0 < p - r = 4(p - 2^254) < 2^127.1`, so every residue has 3 or 4 preimages and `w mod p` is within statistical distance `r (p - r) / (p 2^256) < 2^-128.9` of uniform on `F_p`. Over the 65 words the distance is `eps_coin <= 65 * 2^-128.9 < 2^-122`, and the success bound (9.2) subtracts it.

4.1.2 Stage E: isolating a root of `G`. With `1 <= deg G <= DMAX = 16`, a Cantor-Zassenhaus split with random shifts isolates one linear factor in at most `Z = 64` rounds at degree `<= 16`; `eps_iso <= 120 (1/2 + 2^-127)^64 < 2^-48` bounds the probability that 64 rounds fail to isolate a root when `deg G >= 1` (derived in section 9.4).

### 4.2 Machine model and charging rules (summary; `C(8) = 384`)

Every field operation, load, store, control operation and random word is one primitive operation; `C(r) = 216 + 21 r = 384` primitive operations is one target-compression unit. The register file is 64 words of 256 bits (the machine restriction of claim.json: it holds the 16 values and 15 twiddles of a radix-16 block, or the 32 values and 28 of the 31 twiddles of a radix-32 block; every other value, the 3 spilled twiddles of a radix-32 group included, is charged as a load or store; a load or store of a data word of a block of a transform pass is one operation, its address the base plus index of the load or store itself: one load per word fetched from memory and one store per word written, the wording of the accepted entries `89b451ff` and `070a02b2`), the only register assumption. There is no shared twiddle table (the block products of 4.4 keep their short per-call tables of outer twiddles, charged as before): every product pass of `k <= 4` layers at level `l0` of a `2^a`-point row forms its twiddles as running factors - per pass and layer the step and chain constants (`150` operations: at most 64 squarings, the loop, 4 loads and stores); per position `j` (`2^(a-l0-k)` of them) the running root advanced by one multiplication, `k - 1` squarings and `2^k - 1 - k` multiplications by register constants give its `2^k - 1` twiddles, kept in registers, plus 5 control (`2^k + 4`); the `2^l0` blocks that share them each load `2^k` values and store `2^k` values at one operation each (base plus index), make `k 2^(k-1)` butterflies at 3, plus 5 control (`2 * 2^k + 3 k 2^(k-1) + 5`) (rows C and D carry them, row B keeps the charges of `3dedfa3c`); the truncated passes of stage C (4.3T) take their twiddles from two-level root tables of `4 x 4,096` words in the stage's constant table, built in row C (10 operations per entry) and freed at the end of the stage; the algorithm runs on one thread, no dispatch. Allocation: one preallocated arena; a block is a 64-byte header plus the payload rounded up to a multiple of 64 bytes. A block of more than `2^21` bytes is served by the two-ended pool (one region, two ends, first-fit in address order, the statements marked `# pool:H` using the high end and, with the depth-parity placement of section 7, the end `(j + bit8) mod 2` of a half-gcd node at depth `j`); every smaller block by its slab class (the least `j >= 7` with `2^j >= need`, a slot of `2^j` bytes). The allocators are charged per executed load, store, comparison, branch and address computation, inside the stage rows (a pool request `97` operations besides the walk and `13` per block examined, a slab request at most `126`, a free `81` for a slab block and at most `105` for a pool block). The memory of both allocators is the arena of section 7.

### 4.3T Stage C in the value domain on truncated point sets (the method of bradcush `b30de9bf`/`a41aecdd`, 91 of 128 nodes)

Point sets. `N = 2^32` divides `p - 1` (2-adicity 32). Let `H_N` be the subgroup of order `N` and `Y = X^(2^25)`. `H_N` is the union of the 128 depth-7 nodes `{x : x^(2^25) = r_j}`, `r_j` the 128-th roots of unity in transform (bit-reversed) order; `O1` is the union of the first 91 nodes, `n' = 91 * 2^25 = 3,053,453,312 >= m + 1 = 3,051,757,813` points, and `O2` the same 91 nodes of the coset `5 H_N` (`x^(2^25) = r'_j = 5^(2^25) r_j`). The second set is a coset by 5, not by an element of order `2N`, because the 2-adicity 32 leaves no element of order `2^33`. 5 generates `F_p^*` (the multiplicative generator of the Pallas field), so `5^(2^32) != 1`, `5 H_N != H_N` and `O2` is disjoint from `O1`; also `r'_j^128 = 5^(2^32) != 1`, so no `r'_j` is a 128-th root of unity. `P1 = prod_{j<91} (Y - r_j)` has degree `n'`, vanishes on `O1` and is the nonzero constant `P1(r'_j)` on node `j` of `O2`; `delta_j = 1/P1(r'_j)` (91 table constants).

Truncated transforms (bradcush `b30de9bf` 4.3, generalized as the truncated Fourier transform of van der Hoeven, ISSAC 2004). A polynomial of degree `< n'` is `sum_{k<128} P_k Y^k` with `deg P_k < 2^25` and `P_k = 0` for `k >= 91`; its values on the 91 nodes determine it and are determined by it (the CRT for the 91 coprime moduli `Y - r_j`, whose product `P1` has degree `n'`). The forward transform runs the top 3 layers on all `N/8` offsets (no truncation saving is charged), the middle layers (five passes of radix 32) only on the blocks above present nodes, and the bottom 4 layers on the `n'` points. The inverse runs the same layers in reverse, scales each 16-point block of its bottom pass by `diag(1, c^-1 J)` (`c = y^16` of the block, `V^T V = 16 diag(1, cJ)`; 15 multiplications and the load of `c^-1`, 17 operations per block), and recovers the residues of the dropped part `[91, 128)`, the maximal subtrees `{91}`, `{92..95}`, `{96..127}` (depths 7, 5, 2), from the known zero chunks `P_k = 0` along their paths to the root, as bradcush recovers the one dropped leaf; this is charged 10 operations (3 multiplications, 3 additions, a load and a store) per point of a dropped subtree per layer of its path. The change between `H_N` and `5 H_N` multiplies coefficient `i` by `5^(+-i)`: the fused top pass applies it between its inverse and forward layers (16 operations per 8-point block: a running factor and its seven offsets). The positions above `n'` that a transform touches are those of layers 1-8 (the top pass over all `N` points, the first middle pass, the recovered subtrees). Layers 1-8 act on each class of the `256` positions with equal low 24 bits separately (`182` in `O1`, `74` above `n'`), so they run class-batch by class-batch, `1,024` batches of `16,384` classes, the `74` positions above `n'` of each class of the batch held in one batch buffer of `74 * 16,384 = 1,212,416` words and discarded after the batch (one transform runs at a time); the passes below layer 8 touch only the `n'` positions. Charged once per batch: the 8 groups, the pass overhead and the batch loop of the first middle pass (`8 * 42 + 20 + 3`), the top-pass overhead with its 32 inner loops, one per node-in-lane and half (`60 + 20 + 32 * 5`), the path constants of each recovery (`128`: 14 path levels x 3 constants, LD 2 each, and 3 loops, rounded up), and before the top of each truncated forward the zero-fill of the `163,840` coefficient positions of lane 5 above `n'` (a store, 2, each and the loop). The passes are fused as in `b30de9bf` 4.5 under the declared 64-word register file (4.2), the 32 layers split 3 | 5, 5, 5, 5, 5 | 4 (the cheapest split, `TR_CFG`): a bottom pass (16-point blocks: forward layers, the pointwise map, inverse layers; one set of 15 twiddles for both directions, 19 operations per block: two loads from the two-level table, one multiplication, three squarings, eleven multiplications by register constants; `V^T V = 16 diag(1, cJ)`), five middle passes of radix 32 (per block 32 loads and 32 stores at one operation each, 80 butterflies, the loads of the 3 twiddles that do not fit beside the 32 values (6) and 5 control, 315; per group the 31 twiddles from the two-level table, 4 + 1 + 4 + 22 operations, the stores of the 3 spilled ones and control, 42), and a top pass that fuses the inverse top of one set with the forward top of the other.

Montgomery powering (`b30de9bf` 4.5). For residues of degree `< n'`, `Mont(A, B) = (A B + u g)/P1` with `u = -A B / g mod P1` (`deg u < n'`); the division by `P1` is exact, `Mont(A, B) = A B / P1 mod g`, and `deg Mont(A, A) <= n' - 2`, so `X Mont(A, A)` has degree `< n'`. A residue `A` (representing `S^e P1`) is held by its values on `O1` and on `O2`, each up to a tracked scalar. One step: `U = A^2 k1` on `O1` (`k1 = -1/(N^3 g)` there; `u` is determined by its values on `O1`); `U` to `O2` (truncated inverse on `O1`, truncated forward on `O2`); `B2 = (A2^2 + U g) delta_j` on node `j` of `O2`, which is `Mont(A, A)` up to the tracked scalar because `P1 = 1/delta_j` there, times the point `x` when the exponent bit is 1; `B2` to `O1` (truncated inverse on `O2`, truncated forward on `O1`). No `1/N` is executed inside the steps (the scalars are tracked, 2 operations per step). Per point and step: on `O1` `sqr, LD k1, mul` (4); on `O2` `LD A2, sqr, LD g, mul, add`, the multiplication by `delta_j`, `ST` (10) and the load of `delta_j` per block (2); 3 more for a 1-bit (the load of the point and a multiplication).

Entry and exit. `g` (coefficients from stage B, its slots above `m` zeroed) goes to `O1` and `O2` (a scaling pass and a truncated forward each). The start residue is `A0 = X^v P1 mod g`, `v = 2^29 = 536,870,912` (VSHIFT = 2): `q = floor(X^v P1 / g)` has `ell = v + n' - m + 1 = 538,566,413` coefficients and is formed from the Newton reciprocal of the reversed `g` and one product (transforms of up to `3*2^29` points with running twiddle factors, 4.2); on node `j` of `O2`, `x^v P1(x) = r'_j^16 P1(r'_j)` is a constant (`v = 16 * 2^25`), so `A0 = x^v P1 - q g` there is one truncated forward of `q` and one pointwise pass (8 per point); then `A0` goes to `O1`. `k1` is formed by chunked batch inversion on `O1` (chunks of `2^16` points: prefix products, one inversion, two multiplications per point); each chunk product is tested for zero before its inversion (2 per chunk), and a zero ends the trial: for fixed `x != 0`, `g_c(x)` is a polynomial in `c` of degree `D - 1` with leading coefficient `D f_D(0) != 0`, so over the centre `P(g_c vanishes somewhere on O1) <= n' (D - 1) / p = eps_g < 2^-189` (9.2). The exit is one step with multiplier 1 (`Mont(A, 1)`) and two truncated inverses with their scaling, which return `kappa R` (`kappa` the tracked scalar) and `g` in coefficient form; the gcd is scale-invariant, so stage D receives `kappa R - kappa`. There are `224` squaring steps, `45` of them also multiplying by `S`.

## 5. Why the output is a collision

## 9. The premise and the success bound

### 9.1 H-ONE
The number of centres `c` with `1 <= k(c) <= 16` is at least `q p = 0.3931 p`, `k(c)` the number of nonzero squares `S` with `g_c(S) = 0` (`= deg G`). The premise states `q = 0.3931`, the Poisson(1/2) law value `0.39346933` less the extrapolation allowance stated exactly as `0.0003693` (`0.39346933 - 0.0003693 = 0.39310003`, rounded to `q = 0.3931`), also below the four-moment Bonferroni bound `151/384 = 0.3932292` (9.3); the same value as cryptogakusei's `4888e783`. The toy-field range at `p = 1,048,627` (down to `0.39214`) lies within the deviation scale `1.36/sqrt(p) = 0.00133` of the law; at the Pallas prime that scale is below `2^-126`, far inside the allowance `0.0003693`. The extrapolation, the monodromy theorem at N = 2, 3 and the toy-field and organizer-run evidence are in the claim.json heuristic `H-ONE` and sections 10.3, 10.5.1.

### 9.2 The success bound
The `K = 1` centre is a fresh draw. For a centre `c` let `E_c` be the event `1 <= k(c) <= DMAX` (H-ONE, `P(E_c) >= q = 0.3931`) and `N_c` the event that the remainder sequence of `(g_c, R_c - 1)` is normal down to its gcd (H-NORMAL, 9.5, `P(not N_c) <= delta = 0.003`). The value-domain stage C reproduces `R = S^((p-1)/2) mod g` exactly (Montgomery products on the truncated point sets, 4.3T) and adds no premise; it needs `g_c` nonzero on `O1`, which fails with probability at most `eps_g = n' (D - 1) / p < 2^-189` over the centre (`n' = 3,053,453,312 < 2^31.51`, `D - 1 = 6,103,515,624 < 2^32.51`, `p > 2^254`; 4.3T). If `E_c` and `N_c` hold and `g_c` has no zero on `O1`, stages C and D run to their end and return `G = gcd(g_c, R_c - 1)`; a successful isolation then ends in a verified collision. For `c` uniform `P(E_c and N_c) >= q - delta`, so with the one centre (the event `g_c` zero on `O1` subtracted as `eps_g`)

`success = 1 - (1 - q + delta)^K - K (eps_coin + eps_iso + eps_g) = q - delta - eps_coin - eps_iso - eps_g`, `K = 1`.

Transfer to the written sampler (F-EVAL-001): `q - delta - eps_iso - eps_g` bounds the success probability of the run whose draws are exactly uniform on `F_p` (the premises and the isolation lemma are stated for uniform draws). The success of a run is an event of the vector of its draws, and the actual draws of 4.1.1 are within total variation `eps_coin` of the uniform vector, so the actual success probability is at least the ideal one minus `eps_coin`.

With `q = 0.3931`, `delta = 0.003`, `eps_iso < 2^-48` (9.4), `eps_coin < 2^-122` (4.1.1) and `eps_g < 2^-189`: `q - delta = 0.3901`, and the value the formula gives with these bounds is `0.390099999999996447 >= 0.39` (`0.3901` with `eps = 0`; `eps_coin` and `eps_g` change it only below the 30th decimal). The bound stays at or above `0.39` for every `delta <= 0.0030999` (`q - 0.39 - eps_coin - eps_iso - eps_g`), above the stated `delta = 0.003`; the delta stated in H-NORMAL (9.5) is the delta used here. The probability is over the random words of 4.1.1 for the fixed target, not over targets and not a sampled frequency.

### 9.3 Monodromy (support for H-ONE)
The roots of `G(c,t) = g_c(t^2)` come in pairs `+-t_i`, so the monodromy lies in the hyperoctahedral group `B_m` and `k(c)` counts positive Frobenius fixed points; for `B_m` this is Poisson(1/2) in the limit, `P(k >= 1) = 1 - e^(-1/2) = 0.3934693`, and Bonferroni at order 4 gives `P >= 151/384 = 0.3932292`. A theorem at two and three layers (Aubry-Perret, monodromy `B_12`, `B_62`); false for permutation polynomials, for decomposable `F` with imprimitive monodromy, and at one layer.

### 9.4 Isolation lemma
With `1 <= deg G <= 16`, a random-shift split isolates a linear factor within `Z = 64` rounds except with probability `eps_iso < 2^-48`. Finite derivation: `G` divides both `g_c` and `S^((p-1)/2) - 1`, so it is squarefree and splits into `d = deg G <= 16` distinct linear factors `X - t_i` over `F_p`. A round with shift `a` keeps a nontrivial part of the current factor `H` under `gcd(H, (X + a)^((p-1)/2) - 1)` (or `X + a` itself when `a = -t_i`), so two roots `t_i != t_j` stay together only if `chi(t_i + a) = chi(t_j + a)` or `a` is in `{-t_i, -t_j}`. Since `sum_a chi((a + t_i)(a + t_j)) = -1` for `t_i != t_j`, exactly `(p - 3)/2` shifts give equal nonzero characters, so for `a` uniform on `F_p` the pair stays together with probability at most `((p - 3)/2 + 2)/p = 1/2 + 1/(2p)`; each shift is a fresh random word reduced mod `p`, within statistical distance `2^-128.9` of uniform (4.1.1), so per round the bound is `1/2 + 2^-127`, independently across rounds. The parts are nested, so the factor kept after 64 rounds holds two roots only if one of the at most `C(16,2) = 120` pairs was never separated in 64 rounds. By the union bound `eps_iso <= 120 (1/2 + 2^-127)^64 < 6.6e-18`, below the stated `2^-48 = 3.55e-15`; the looser stated value `2^-48` is kept, so every other number is unchanged.
