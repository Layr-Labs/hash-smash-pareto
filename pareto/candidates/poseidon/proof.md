## 2. Two free rounds: a line in the input plane

Notation. `p = 0x40000000000000000000000000000000224698fc094cf91b992d30ed00000001`, `p mod 5 = 2`, so `gcd(5, p-1) = 1` and `x -> x^5` is a bijection of `F_p` with inverse `x -> x^e`, `e = (4(p-1)+1)/5` (254 bits). `M` is the deployed 3x3 MDS, `c_{i,k}` the deployed round constant `k` of round `i` (read from the organizer constants; never regenerated).

2.1 Round 0. With `U = (nk + c_{0,0})^5`, `V = (rho + c_{0,1})^5`, `K = (2^65 + c_{0,2})^5` the state after round 0 is `M (U, V, K)^T`. `(nk, rho) -> (U, V)` is a bijection of `[0,p)^2` (inverse `nk = U^e - c_{0,0}`, `rho = V^e - c_{0,1}`), so every `(U, V)` has exactly one canonical preimage. `K` is a constant.

2.2 Round 1. The S-box input is `x_k = M_{k0} U + M_{k1} V + b_k`, `b_k = M_{k2} K + c_{1,k}`, affine in `(U, V)`. The algorithm uses the line `j = 0`. With `I = {i1, i2} = {0,1,2} \ {j}`, let `Q = (U_Q, V_Q)` be the solution of `x_{i1} = x_{i2} = 0` (the 2x2 determinant `M_{i1,0} M_{i2,1} - M_{i1,1} M_{i2,0}` is a minor of the MDS, nonzero on the deployed constants, checked). Let `(a, b) = (M_{j,1}, -M_{j,0})` and `(U, V) = Q + tau (a, b)`. Then `x_j = kappa` is constant and `x_i = d_i tau` for `i in I`, `d_i = M_{i0} a + M_{i1} b` (`d_j = 0`). With `W = tau^5` the round-1 S-box output is `v0 + W v1`, `v0 = kappa^5 e_j`, `v1 = sum_{i in I} d_i^5 e_i` (the supports are disjoint). After the round-1 MDS and the round-2 constants the state is `alpha + beta W` with `alpha = M v0 + c_2`, `beta = M v1`, affine in `W`.

2.3 Digest polynomial. Rounds 2, 3 (full), 4, 5, 6, 7, 8, 9, 10 (partial), 60, 61, 62, 63 (full) put thirteen S-box layers on top of an affine map, and the digest is row 0 of the last MDS. So the digest equals `F(W)` with `deg F <= 5^13 = D = 1,220,703,125`. The leading coefficient is obtained by propagating leading coefficients through the thirteen layers (a partial round contributes only coordinate 0 at the top degree); on the deployed constants it is nonzero for the line used: `f_D(0) = 0x28cf6129b49568f76cbbcb977dae09a15d9b0b6c18a191886de5f7aae3a6297b` (computed by the propagation just described, with the same code reproducing the constants of the executed entries at r = 3, 4, 5; so `deg F = D` exactly). For random `tau`, `F(tau^5)` equals the reference hash of the canonical inputs built from `tau` (checked at the executed round counts on random `tau` against an independent big-integer reference that reproduces the 11 public Orchard vectors).

2.4 Collision criterion. If `W1 != W2` and `F(W1) = F(W2)` then `tau1 != tau2` (`x -> x^5` is injective), hence `(U, V)` differ (`(a, b) != 0`), hence the canonical pairs `(nk, rho)` differ, and the digests are equal. Every `W in F_p` is `tau^5` for exactly one `tau`.

## 3. Odd part with a centre

For a centre `c in F_p` write `F(c + s) - F(c - s) = 2 s g_c(s^2)`. Because `D = 2m + 1` with `m = 610,351,562`, `g_c` has degree exactly `m` and leading coefficient `f_D(0)` (independent of `c`, nonzero), so `g_c` can be made monic. A collision pair with midpoint `c` is exactly `W1 = c + s`, `W2 = c - s` with `s != 0` in `F_p`, i.e. `S = s^2` a nonzero square with `g_c(S) = 0`. The useful roots are the roots in `F_p` with `S^((p-1)/2) = 1`: they are the roots of `gcd(g_c, S^((p-1)/2) - 1)` (roots that are nonsquares give `s` outside `F_p`; `S = 0` is not a root of `S^((p-1)/2) - 1`). This gcd divides the squarefree `S^((p-1)/2) - 1`, so it is a product of `k(c)` distinct linear factors over `F_p` (9.1); stage D computes instead the gcd of 4.3G, whose roots are their `2^27`-th powers.

Construction of `g_c` by evaluation. `H = 805,306,368 = 3 * 2^28` divides `p - 1` (`p - 1 = 2^32 * 3 * q`) and `H >= m + 1`. Let `omega` be a primitive `H`-th root of unity and `zeta` with `zeta^2 = omega`. Then `g_c(omega^i) = (F(c + zeta^i) - F(c - zeta^i)) / (2 zeta^i)`, `i = 0..H-1`; one inverse transform of size `H` returns the coefficients of `g_c` (the `H - m - 1` high coefficients are zero because `deg g_c = m < H`; interpolation is exact). Each of the `2H = 1,610,612,736` evaluations of `F` is charged at the operations it executes (the line evaluation `tail_eval`): the affine start `alpha + beta W` (3 multiplications, 3 additions: 6), round 2 (three S-boxes `x^5` of 3 operations each and the MDS, 9 multiplications and 6 additions: 24; its constants are in `alpha`), round 3 (3 constant additions, 9, 15: 27), the seven partial rounds (3 + 3 + 15 = 21 each), rounds 60-62 (27 each) and round 63 (3 + 9 and row 0 of the MDS, 3 multiplications and 2 additions: 17), `155 + 21 r = 302` operations at `r = 7`; rounds 0 and 1 are not executed (section 2). The loop work (two point additions, one subtraction, one multiplication by `1/(2 zeta^i)`, the recurrences `zeta^{i+1}`, `zeta^{-i-1}`, the store with its address, the loop control and the bit-reversed index) is charged on top (stage B, section 6), with the twiddle table of the transform, built by stage B (4.2).

## 4. The algorithm (one centre, one thread)

### 4.1 Stages, coins and the stopping rule

```
init:   constants (once; no twiddle table: stage B builds the table of its transform; the product passes of stages C and D use running twiddle factors, 4.2)
setup:  the line (line_setup) (once)
for t = 1, ..., K (K = 1):            [the test t <= K is made at the start of the trial; no exit except success]
  A  c := (w1 * 2^256 + w2) mod p from two fresh random words w1, w2 (4.1.1)
  B  g := monic g_c, by section 3 (1,610,612,736 evaluations + one inverse NTT of size 805,306,368 + the nonzero-leading-coefficient test + normalisation)
  C  g := g^(27): 27 Graeffe steps on O1 (section 4.3G); R := S^((p-1)/2^28) mod g, in the value domain on the truncated point sets O1, O2 of n' = 610,795,520 points (section 4.3T): 199 squaring steps, 45 of them also multiplying by S
  D  G := gcd(g, R - 1) (monic): the inversion-free half-gcd on three rows with the in-place applies of the memory cap (section 4.4), charged for the normal remainder sequence with the quotient and return tests; on any other case ABORT (6.3)
  E  if deg G = 0 or deg G > DMAX: trial ends. Otherwise isolate a root y of G (4.1.2); if none within Z = 64 rounds: trial ends.
  F  u := a 2^28-th root of y (28 Tonelli-Shanks square roots, 2-adicity 32); for j = 0, ..., 2^27 - 1: s := u mu^j, W1 = c + s, W2 = c - s, until F(W1) = F(W2) (4.1.3); tau_i = W_i^e; (U,V)_i = Q + tau_i (a,b); nk_i = U_i^e - c_{0,0}, rho_i = V_i^e - c_{0,1}
  G  verify: the two reference hashes (300 operations each) are equal and the pairs differ -> output; otherwise the trial ends
```

4.1.1 Coins (ruling `04c0dd43`, finding F-EVAL-001). The only randomness is the cost-model random-word primitive. Every random field element of the algorithm (the centre `c` of stage A and each shift of stage E) is drawn from two fresh 256-bit words `w1, w2`: each is reduced mod `p` by three conditional subtractions (exact, `2^256 < 4p`), and `x = (w1 mod p) * (2^256 mod p) + (w2 mod p)` in `F_p`, i.e. `x = (w1 2^256 + w2) mod p` with `w1 2^256 + w2` uniform on `[0, 2^512)`. There is no rejection and no retry. A draw is 63 operations: per word 1 random-word operation, 1 load, 1 store, 3 control, the reduction 9 and its loop control 11 (26 per word, 52), two Montgomery conversions 2, the load of the constant `2^256 mod p` 1, one multiplication 1, one addition 1, entry 2, the two addresses 4. At most `1 + Z = 65` draws (`130` words) per run. With `2^512 = Q p + r`, each residue has `Q` or `Q + 1` preimages, so one draw is within statistical distance `r (p - r) / (p 2^512) <= p / 2^512 = 2^-258.0` of uniform on `F_p`; the 65 draws are independent, so the joint distribution of all the coins of a run is within `eps_coin = 65 p / 2^512 <= 1.404e-76` of the distribution with every draw exactly uniform (total variation is subadditive over independent components).

4.1.2 Stage E: isolating a root of `G`. With `1 <= deg G <= DMAX = 16`, a Cantor-Zassenhaus split with random shifts isolates one linear factor in at most `Z = 64` rounds at degree `<= 16`; `eps_iso <= 2.371e-15` bounds the probability that 64 rounds fail to isolate a root when `deg G >= 1` (section 9.4).

4.1.3 Stage F: the root of `g_c` above `y`. By 4.3G, `y = S^(2^27)` for a usable root `S` of `g_c`, and the solutions of `S'^(2^27) = y` are `u^2 mu^(2j)`, `j < 2^27`, where `u^(2^28) = y` and `mu` is a fixed primitive `2^28`-th root of unity (`2^28 | p - 1`; a constant of the offline derivation, 6.2). `u` comes from 28 successive Tonelli-Shanks square roots: `y` is a `2^28`-th power, and if `x` is a `2^k`-th power with `1 <= k <= 28`, both square roots of `x` are `2^(k-1)`-th powers (`-1` is a `2^(k-1)`-th power, `2^k | p - 1`). The scan takes `s = u mu^j` for `j = 0, 1, ..., 2^27 - 1` and stops at the first `j` with `F(c + s) = F(c - s)` (two line evaluations of section 3). For `S' = s^2` a root of `g_c` this holds, because `F(c + s) - F(c - s) = 2 s g_c(s^2)`, so the scan stops at the latest at the `j` of `S`; any stop has `s != 0` (`y != 0`) and `F(c + s) = F(c - s)`, a collision by 2.4. Charge per candidate: `s <- s mu` 1, `c + s` and `c - s` 2, two line evaluations `2 * 302`, their calls 4, the comparison and branch 2, the loop control 3: `616`; at most `2^27` candidates, `82,678,120,448`, and the loop exit 2. The 28 square roots are charged `47,012` each (the whole row F of the algorithm without the prefix, a square root and the back-map), `1,316,336`, and the back-map `47,012`: row F = `82,679,483,798`.

### 4.2 Machine model and charging rules (summary; `C(7) = 363`)

Every field operation, load, store, control operation and random word is one primitive operation; `C(r) = 216 + 21 r = 363` primitive operations is one target-compression unit. The register file is the machine restriction of claim.json: one file of 392 words, 256 field registers of 256 bits plus 136 integer address registers, counted in the memory (7). The 136 integer registers are those of a call of a radix-128 middle pass (4.3T), the most of any kernel: the 128 row bases, the group index, the two indices and the two bases of the two-level root table, the position offset, the loop bound and the stack pointer (fewer in the other kernels; a block of a 7-layer product pass holds its 128 row bases and at most 7 more). The field registers (they hold the 16 values and 15 twiddles of a radix-16 block or group, the 64 values and 63 twiddles of a radix-64 block, the 128 values and 127 twiddles of a radix-128 block, or the `2^k <= 128` values and `2^k - 1` twiddles of a block-form product block of `k <= 7` layers; every other value is charged as a load or store; a load or store of a data word of a block of a transform pass of 4.3T is one operation, its address the base plus index of the load or store itself: one load per word fetched from memory and one store per word written, the wording of the accepted entries `89b451ff` and `070a02b2`) and the 136 integer registers are the only register assumption; the algorithm runs on one thread, no dispatch. The block loops of the transform passes of rows C and D are unrolled by four: a block is charged 3 control in place of 5 (the loop counter, test and branch, 3 operations per four blocks, charged 1 per block, and the 2 address updates; a block that advances more array pointers is charged 1 more per pointer: the bottom block of a squaring step on `O2` 2 more (data, `A2`, `g`, output; 3 on a 1-bit, the point), the fused Graeffe bottom block 1 more (`E`, `O`, output); a block loop of one or two blocks is straight code). This applies to the radix-16, radix-64 and radix-128 middle blocks (4.3T: 131, 707 and 1,603), the 16-point blocks of the bottom passes of 4.3T, the fused bottom block of a Graeffe step (4.3G), and the blocks of the block-form product passes of stages C and D (below); the fused pointwise passes, the top passes and row B keep their charges. The three further copies of each unrolled block body (the radix-16, radix-64 and radix-128 middle blocks, the five bottom-pass blocks, the fused Graeffe bottom block, and the forward and inverse block-form product-pass blocks of 1 to 7 layers with their twiddle-one variants, each at its full charge), and one copy of each body that is new against the 64-register program text (the radix-64 and radix-128 middle blocks, the product blocks of 5 to 7 layers and the twiddle-one variants), hold `58,604` primitive operations, one 4-byte instruction each (the instruction width of the machine declared by cryptogakusei `1533f8f0`, its H2): `234,416` bytes of code, added to the footprint (section 7). Allocation: one preallocated arena; a block is a 64-byte header plus the payload rounded up to a multiple of 64 bytes. A block of more than `2^19` bytes is served by the two-ended pool (one region, two ends, first-fit in address order, the statements marked `# pool:H` using the high end and, with the depth-parity placement of section 7, the end `(j + bit8) mod 2` of a half-gcd node at depth `j`); every smaller block by its slab class (the least `j >= 7` with `2^j >= need`, a slot of `2^j` bytes). The allocators are charged per executed load, store, comparison, branch and address computation, inside the stage rows (a pool request `97` operations besides the walk and `13` per block examined, a slab request at most `126`, a free `81` for a slab block and at most `105` for a pool block). The memory of both allocators is the arena of section 7. Twiddle tables: none is built in init; stage B builds the table of its transform (`2^(a-1)` entries for `3*2^a` points: its root, 5 operations per entry and the loop) and frees it, charged in row B; the passes of 4.3T use two-level root tables of `4 x 4,096` words (stage C). Every other product pass (the Newton and quotient products of stage C, 4.3T; the node products and the applies of stage D, 4.4) forms its twiddles as running factors, in the block form of our r = 8 entry `27fbfbe7` (the block products of 4.4 keep their short per-call tables of outer twiddles, charged as before): per pass and layer the step and chain constants (`150` operations: at most 64 squarings, the loop, 4 loads and stores); per position `j` (`2^(a-l0-k)` of them) the running root advanced by one multiplication, `k - 1` squarings and `2^k - 1 - k` multiplications by register constants give its `2^k - 1` twiddles, kept in registers, plus 5 control (`2^k + 4`); the `2^l0` blocks that share them each load `2^k` values and store `2^k` values at one operation each (base plus index), make `k 2^(k-1)` butterflies at 3, plus 3 control (the block loop unrolled by four) (`2 * 2^k + 3 k 2^(k-1) + 3`). Stages C and D build no twiddle table. The layers of a row of a product transform are split top-down into passes of at most 7 layers by the cheapest sequence under these charges (a block of `2^k <= 128` values and its `2^k - 1` twiddles in registers), the last pass of a product with a fused pointwise pass at most 4 layers; the rows of the node products and the applies of stage D, which have no fused pass, take up to 7 in their last pass as well. At position `j = 0` of a pass the running root is 1: each of its `2^l0` blocks runs a straight-line variant in which the `2^k - 1` butterflies with twiddle 1 are an addition and a subtraction, 2 operations in place of 3, with 3 control more per pass for the selection (as in our entry `c7ef0551`).

### 4.3G The Graeffe prefix

Definition. For `h` monic of even degree `m` write `h(X) = E(X^2) + X O(X^2)`; its Graeffe transform is `h~(Y) = E(Y)^2 - Y O(Y)^2`, so `h~(X^2) = h(X) h(-X)` and `h~` is monic of degree `m` with roots the squares of the roots of `h` (with multiplicity). Stage C first replaces `g = g_c` by `g^(27)`, 27 Graeffe steps, then computes `R = S^e mod g^(27)`, `e = (p-1)/2^28` (2-adicity 32), and stage D takes `G = gcd(g^(27), R - 1)`.

Lemma. `G` is the product of `(Y - y)` over the distinct values `y = S^(2^27)`, `S` a usable root of `g_c` (a nonzero square in `F_p` with `g_c(S) = 0`, section 3). Proof: `g^(27)(Y) = prod_i (Y - S_i^(2^27))` over the roots `S_i` of `g_c` in an algebraic closure; `Y^e - 1` is squarefree and its roots are the `2^28`-th powers of `F_p^*`. If `S_i^(2^27) = u^(2^28)` with `u` in `F_p^*`, then `S_i = u^2 zeta` with `zeta^(2^27) = 1`, so `zeta` is in `F_p` and `zeta = xi^2` with `xi^(2^28) = 1` (`2^28 | p - 1`), and `S_i = (u xi)^2` is a nonzero square of `F_p`; conversely `S = v^2` gives `S^(2^27) = v^(2^28)`. So `deg G` is the number of distinct `2^27`-th powers of the usable roots: `1 <= deg G <= k(c)` when `k(c) >= 1`, and `deg G = 0` when `k(c) = 0`; the event `E_c` of 9.2 gives `1 <= deg G <= DMAX`.

Execution (on the point set `O1` of 4.3T). One step: `E` (`m/2 + 1` coefficients) and `O` (`m/2`) are read from `g` at stride 2 by the top passes of two truncated forwards, which load only the input blocks below the length (3 or 2 of the 8 per offset, two offset ranges per batch; butterflies only on nonzero inputs; no zero-fill); the fused bottom pass forms `G = (E^2 - y O^2)/N` at each point `y` of `O1` between the forward and the inverse bottom layers (`y` is the last-layer twiddle of its butterfly, in a register: two squarings, two multiplications, one subtraction, 5 per point); one truncated inverse stores the new coefficients into the array of `g` (those above `m` come out zero). `E` and `O` on `O1` use the arrays of `A` on `O2` and of `A` on `O1` before stage C fills them, with a batch buffer of `5,177,344` words of their own, used by one transform at a time and freed after the prefix; no array is added and the high-water mark of section 7 is unchanged. One step is `121,026,349,746` operations (Appendix E.1), 27 steps; stage C then runs 199 squaring steps in place of 226 (the exponent loses 27 low zero bits). A step saves one squaring step (`179,271,858,732`) for `121,026,349,746` and doubles the scan of 4.1.3 (`2^s * 616`); `s = 27` minimises the total.

Every map is exact; no premise is added to the time or the memory. The zero test of `k1` (4.3T) now concerns `g^(27)`: `g^(27)(y) = 0` for `y` in `O1` only if `g_c(x) = 0` for one of the `2^27` values `x` with `x^(2^27) = y` (in `F_p` or an extension); for each such `x`, `g_c(x)` is a polynomial in `c` of degree `D - 1` with leading coefficient `D f_D(0) != 0`, so over the centre `P(g^(27) vanishes on O1) <= 2^27 n' (D - 1) / p = eps_g < 2^-167`.

### 4.3T Stage C in the value domain on truncated point sets (the method of bradcush `b30de9bf`/`a41aecdd`, 1165 of 2048 nodes)

Point sets. `N = 2^30` divides `p - 1` (2-adicity 32). Let `psi` have order `2^31`, `H_N = <psi^2>` and `Y = X^(2^19)`. `H_N` is the union of the 2048 depth-11 nodes `{x : x^(2^19) = r_j}`, `r_j` the 2048-th roots of unity in transform (bit-reversed) order; `O1` is the union of the first 1165 nodes, `n' = 1165 * 2^19 = 610,795,520 >= m + 1 = 610,351,563` points, and `O2` the same 1165 nodes of the coset `psi H_N` (`x^(2^19) = r'_j`, `r'_j^2048 = -1`), disjoint from `O1`. `P1 = prod_{j<1165} (Y - r_j)` has degree `n'`, vanishes on `O1` and is the nonzero constant `P1(r'_j)` on node `j` of `O2`; `delta_j = 1/P1(r'_j)` (1165 table constants).

Truncated transforms (bradcush `b30de9bf` 4.3, generalized as the truncated Fourier transform of van der Hoeven, ISSAC 2004). The inverse runs the same layers in reverse, scales each 8-point block of its bottom pass by `diag(1, c^-1 J)` (`c = y^8` of the block, `V^T V = 8 diag(1, cJ)`; 7 multiplications and the load of `c^-1`, 9 operations per block), and recovers the residues of the dropped part `[1165, 2048)`, the maximal subtrees `{1165}`, `{1166..1167}`, `{1168..1183}`, `{1184..1215}`, `{1216..1279}`, `{1280..1535}`, `{1536..2047}` (depths 11, 10, 7, 6, 5, 3, 2), from the known zero chunks `P_k = 0` along their paths to the root, as bradcush recovers the one dropped leaf; with the value of the path held in a register this is charged 8 operations (3 multiplications, 3 additions, the load of the known value) per point of a dropped subtree per layer of its path and one store (2) per point. The positions above `n'` that a transform touches are held in two buffers (one transform runs at a time). Layers 1-7 (the top pass, the first middle pass and the recoveries of the dropped subtrees of depths 7, 6, 5, 3, 2) act on each class of the `128` positions with equal low 23 bits separately (`73` below `73 * 2^23`, `55` above: the depth-7 nodes 73-127), so they run class-batch by class-batch, `128` batches of `65,536` classes, the `55` positions above of each class of the batch held in a batch buffer of `3,604,480` words and discarded after the batch; the `3 * 2^19 = 1,572,864` positions in `[n', 73 * 2^23)` that the passes below layer 7 touch (the dropped depth-11 nodes 1165-1167, the subtrees of depths 11 and 10) are a tail buffer held whole. Charged once per batch: the 8 groups, the pass overhead and the batch loop of the first middle pass (`8 * 20 + 20 + 3`), the top-pass overhead with its 16 inner loops, one per range of `65,536` consecutive offsets (`60 + 20 + 16 * 5`), and the path constants of the five in-batch recoveries reloaded (`163`: 23 levels, 3 constants each loaded at 2, and 5 loops at 5); before the top of each truncated forward the zero-fill of lane 4 above `n'` (the `7` positions of each class of the batch, per batch, and the tail once; a store, 2, each and the loop). The passes are fused as in `b30de9bf` 4.5 under the 256 field registers of the declared register file (4.2), the 30 layers split 3 | 4, 6, 6, 7 | 4: a bottom pass (16-point blocks: forward layers, the pointwise map, inverse layers; one set of 15 twiddles for both directions, 19 operations per block: two loads from the two-level table, one multiplication, three squarings, eleven multiplications by register constants; `V^T V = 16 diag(1, cJ)` with `c = y^16` of the block, so every inverse bottom pass scales each block by `diag(1, c^-1 J)`: 15 multiplications and the load of `c^-1`, 17 operations per block), a middle pass of radix 16 (per block 16 loads and 16 stores at one operation each, 32 butterflies and 3 control (the block loop unrolled by four, 4.2), 131; the 15 twiddles of a group in registers, formed from the running group root by one multiplication, 3 squarings and 11 multiplications by register constants, 20 per group with its control), two middle passes of radix 64 (per block 64 loads and 64 stores at one operation each, 192 butterflies at 3 and 3 control, 707; per group its 63 twiddles from the running group root by 1 multiplication, 5 squarings and 57 multiplications, held in registers with the 64 values, 68 with its control), and one middle pass of radix 128 (per block 128 loads and 128 stores, 448 butterflies at 3 and 3 control, 1,603; per group its 127 twiddles by 1 multiplication, 6 squarings and 120 multiplications, 132 with its control), and a pruned top pass that fuses the inverse top of one set with the forward top of the other: only the `b = 5` depth-3 subtrees that hold points of the 1165 nodes are formed or read (the butterflies of the 8-point top block counted on the needed and nonzero lanes, `_top_counts`), and the coset twiddle is applied on those `b` blocks.

Montgomery powering (`b30de9bf` 4.5). For residues of degree `< n'`, `Mont(A, B) = (A B + u g)/P1` with `u = -A B / g mod P1` (`deg u < n'`); the division by `P1` is exact, `Mont(A, B) = A B / P1 mod g`, and `deg Mont(A, A) <= n' - 2`, so `X Mont(A, A)` has degree `< n'`. There are `199` squaring steps (the exponent `(p-1)/2^28`, 4.3G), `45` of them also multiplying by `S`.

Exactness and memory. Every map above is exact (Montgomery products of polynomials of degree `< n'`, held bijectively by their values on 1165 nodes); no premise is added to stage C. The live set of the stage is four arrays of `n'` words (`g` on `O2`, `A` on `O2`, `A` on `O1`, `k1` on `O1`), the tail and batch buffer of `5,177,344` words, the tables (`1,195 + 16,384` words: 30 constants, the 1165 `delta_j`, the two-level root tables) and, while `q` is formed, the Newton arrays. ### 4.4 Stage D: the inversion-free half-gcd on three rows (bradcush `4bcabff8`), with the in-place applies of the memory cap

`G = gcd(g, R - 1)` is computed by bradcush's inversion-free half-gcd (entry `4bcabff8`, with the transform reuse of `b30de9bf`; read as text only, ported and charged in this cost model as in our r = 3 entry `bcf8e01c`). Matrices and remainders are kept up to nonzero scalars with pseudo-division (`b^2 a = Q b + e`, `Q` of degree 1 on the normal sequence), so no field inversion runs inside the recursion; the gcd is the same up to a scalar and is made monic at the end. A node of budget `k = 2^j - 1` makes two child calls of budget `2^(j-1) - 1`; its products run on `3 * 2^(j-1)` points, the rows `Y - 1`, `Y + 1`, `Y - i` (`Y = X^n`, `n = 2^(j-1)`), each a power-of-two transform of `n` points in the block form of 4.2 after a twist, joined by a 3-row CRT for `(c, d) = adj(M1)(a, b)` on the top window; then the pseudo-division and the product `M = M1 [[Q, 1], [b^2, 0]] M2` on the two rows `Y - 1`, `Y + 1` only (`2n` points; 2-row CRT `lo = (u + v)/2`, `hi = (u - v)/2` with the `1/2` folded into the `1/n` of the inverse, 10 operations per point). The product needs no third row: on the normal sequence every quotient has degree 1 and `b^2` is a constant, so a matrix of `s` steps has entries of degree at most `s`; the entries of `M1`, `M2` (budget `n - 1`) have degree at most `n - 1` and those of `M` at most `2n - 1 < 2n`, and the values on the `2n` points with `X^(2n) = 1` determine `M` exactly (the 2n-point product of van der Hoeven, arXiv 2212.12389, Prop. 7, here without its leading-coefficient correction). A node reaches its product only after the quotient tests of its children and of its own pseudo-division have passed (6.3), so the degree bound holds whenever the product runs. These `2n` points are the row `Y' - 1` (`Y' = X^(2n)`) of the parent, so the values of `M` there are returned to the parent with no transform; the row `Y - 1` values of each child's matrix are returned by the child, the row values of `M1` are kept from the apply and reused in the product, and of `M2` only the row `Y + 1` is transformed (both rows when its children are base cases, which return coefficients only). The twist roots of order `2n` and `4n` come from the squaring chain of the running twiddle factors of the row transform (4.2); the scales `1/2^a` (`a <= 27`) are a table of 27 words built at the entry of stage D (`1/2 = (p + 1)/2` an immediate, 26 multiplications). The base case (budget 63) runs two remainder steps per pass over its window. Driver: while `(n - 1)/2 >= 127`, one outer step calls the node on the top window of the pair with `k = 2^j - 1` the largest with `k <= min(2^26 - 1, (n - 1)/2)`, applies `adj(M)` to the whole pair in place, and makes one division with the quotient test; the apply is that of the memory cap (the method of weijiekoh `a78f526e`, its `mat_apply` LMAX, as in `2bacc5bb`): an apply to a pair longer than `LMAX = 3 * 2^26` coefficients is done by the block products of scheme (a) at the block length `3 * 2^23` (transforms of `3 * 2^24` points: the radix-3 layer and three rows of `2^24` points, charged as every `3*2^a`-point transform of this model), each block of the operands transformed once, the transforms of a slot multiplied pointwise and summed, and each output slot inverse transformed and overlap-added in place into the output array. The last outer step (degree below `255`) is the lean cofactor-free half-gcd of bradcush `e6dcb600`/`1aa56884` as in `2bacc5bb`, and below degree `192` classical division steps finish. The working arrays of a node live in one bump arena (an allocation or release is 10 operations) of `1,073,741,568` words at `j = 26`, the peak of its recursion; the cap `j <= 26` bounds the arena, which with the pair and the matrix of the outer step sets the high-water mark of the trial (section 7). On the normal sequence every length, budget and allocation is a function of `m` alone. The row is charged for the normal remainder sequence (every quotient of degree 1), the case of the premise `H-NORMAL` (9.5): every division and pseudo-division tests that its quotient has degree 1 and every call tests on return that it removed exactly its budget (2 operations each), and a zero remainder also ends the trial; on any other case the trial ABORTs (the allocator is reset and the run ends without output, section 6.3). By the prefix lemma of 6.3 every trial executes a prefix of the operations and of the allocation sequence charged for the normal case, so the time bound of section 6 and the memory bound of section 7 hold for every remainder sequence; only the success probability depends on the sequence (9.2). The apply of an outer step on the inversion-free node (the direct whole-pair and fixed-slot apply plans of 0xplemonade's entry `ff21bd28`, read as text, re-implemented and charged in this cost model) is the cheaper by charge of the in-place apply above and these two plans, here a plan of `ff21bd28` at all 35 such steps (6 fixed-slot, 29 direct). With `h = 2^j - 1`, `(c, d) = adj(M)(a, b)` has `lc = la - h` and `lc - 1` coefficients (the high coefficients cancel). A plan uses one transform size `N = 3 * 2^e <= 3 * 2^26` and one of two forms, both priced at every `e = 2, 3, ...` up to the first with `N >= lc` (8 control operations and the plan set-up per size); 80 operations of entry, 448 for the plan scale and 22 for the two length checks. A transform of an array of `l <= N` coefficients is `6` plus the radix-3 input stage over the `l` coefficients plus three rows of block-form passes (4.2); an inverse is `3` plus three rows of inverse passes plus the radix-3 output stage over the coefficients formed; the scaling of `t` outputs into their array is `8t + 5`. Both forms first transform the four entries (`h + 1`, `h`, `h`, `h - 1` coefficients) into four spectra of `N` points and free the coefficient matrix. (i) Direct whole-pair (`N >= lc`): `a` and `b` are folded modulo `X^N - 1` (10 per coefficient beyond `N`) and transformed into the operand spectra `A` and `B`; one pass over the `N` points forms `C = r22 A - r12 B` over `A` and `D = r11 B - r21 A` over `B` (six loads with their address operations, four multiplications, a subtraction, an addition and two stores: 20 per point, and the eight-element loop `2 + for8(N)`); the two inverses form the first `lc` and `lc - 1` coefficients, written scaled over `a` and `b`; since `deg c, deg d < lc <= N` the cyclic results are exact. (ii) Fixed-slot (`B = N - h > 0`): the outputs are cut into `nb = ceil(lc / B)` blocks of `B` coefficients, handled from the highest to the lowest (`3 nb + 6` of loop control); block `i` transforms the windows `[max(0, iB - h), min((i + 1) B, lc))` of `a` and of `b` (at most `N` coefficients) into `A` and `B`, forms `C` and `D` in one pass (24 per point and `2 + for8(N)`), inverse transforms both and writes the scaled outputs of the block over the same positions of `a` and `b`; 20 of control per block. A window of `w <= N` coefficients times an entry of at most `h + 1` gives at most `w + h` coefficients, so the cyclic wrap reaches only positions below `h`, which are not outputs of a block `i > 0`, and block 0 has no wrap; block `i` writes positions `[iB, (i + 1) B)` and the blocks after it read only positions below `iB`. ## 5. Why the output is a collision

By 2.4 any `W1 != W2` with `F(W1) = F(W2)` maps back to two distinct canonical pairs with equal digests. Stage D returns `G = gcd(g, R - 1)`, whose roots are the values `y = S^(2^27)` of the usable roots `S` of `g_c` (4.3G); stage F stops only at an `s != 0` with `F(c + s) = F(c - s)` (4.1.3), so `W1 = c + s != c - s = W2`. Stage G verifies both inputs with the reference hash before the algorithm outputs, so a returned pair is a verified collision.

### 9.3 Monodromy (support for H-ONE)
The roots of `G(c,t) = g_c(t^2)` come in pairs `+-t_i`, so the monodromy lies in the hyperoctahedral group `B_m` and `k(c)` counts positive Frobenius fixed points; for `B_m` this is Poisson(1/2) in the limit, `P(k >= 1) = 1 - e^(-1/2) = 0.3934693`, and Bonferroni at order 4 gives `P >= 151/384 = 0.3932292`. A theorem at two and three layers (Aubry-Perret, monodromy `B_12`, `B_62`); false for permutation polynomials, for decomposable `F` with imprimitive monodromy, and at one layer.

### 9.4 Isolation lemma
With `1 <= deg G <= 16`, a random-shift split isolates a linear factor within `Z = 64` rounds except with probability `eps_iso <= 2.371e-15`. Finite derivation: `G` divides `Y^((p-1)/2^28) - 1` (4.3G), a divisor of `Y^(p-1) - 1`, so it is squarefree and splits into `d = deg G <= 16` distinct linear factors `X - t_i` over `F_p`. A round with shift `a` keeps a nontrivial part of the current factor `H` under `gcd(H, (X + a)^((p-1)/2) - 1)` (or `X + a` itself when `a = -t_i`), so two roots `t_i != t_j` stay together only if `chi(t_i + a) = chi(t_j + a)` or `a` is in `{-t_i, -t_j}`. Since `sum_a chi((a + t_i)(a + t_j)) = -1` for `t_i != t_j`, exactly `(p - 3)/2` shifts give equal nonzero characters, so for `a` uniform on `F_p` the pair stays together with probability at most `((p - 3)/2 + 2)/p = 1/2 + 1/(2p)`; each shift is a fresh random word reduced mod `p`, within statistical distance `2^-128` of uniform (4.1.1), so per round the bound is `1/2 + 2^-127`, independently across rounds. The parts are nested, so the factor kept after 64 rounds holds two roots only if one of the at most `C(16,2) = 120` pairs was never separated in 64 rounds. By the union bound `eps_iso <= 120 (1/2 + 2^-127)^64 < 6.6e-18 <= 2.371e-15`; the looser stated value `2.371e-15` is kept, so every other number is unchanged.
